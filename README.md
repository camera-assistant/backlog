# backlog

The backlog of Camera Assistant (a working title), a local recorder for the cameras in your home.

This repository hosts the issues of the [Camera Assistant Project Board](https://github.com/orgs/camera-assistant/projects/2) and the technical plans behind them.

- **Epics** are the larger goals on the board. Each epic links its plan, and its sub-issues are the steps of that plan, each with a task list.
- **Plans** are in [docs/plans](docs/plans): the technical companion of each epic, so the reasoning is public and can be fed to tooling.

## Status

The project has just started. Read the [architecture overview](docs/architecture.md) first. The epics are on the board, each with its plan and its sub-issues. Milestones say which phase an issue belongs to: Preview, MVP or AVP (after the MVP).

## Want to help?

Pick a sub-issue that has nobody assigned, and say in a comment that you are taking it. For a new idea or a question, start a [discussion](https://github.com/camera-assistant/camera-assistant/discussions).

Working with a coding agent? Point it to [AGENTS.md](AGENTS.md) first.
